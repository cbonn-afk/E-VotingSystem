## Frontend Purpose

This application provides the user interface for Truant's ordering, BOM
costing, statements of account, payments, production, employee, accounting,
reporting, and administration workflows.

The Laravel backend remains responsible for authentication, authorization,
validation, business rules, and data access. Hiding a frontend menu or page is
not a substitute for backend permission enforcement.

## Getting Started

Install dependencies and run the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

See the [root project README](../README.md) for the full architecture, roadmap,
contributors, and repository information. Backend setup is documented in the
[backend README](../truant_backend/README.md).
